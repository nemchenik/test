# Бордовое ателье

Премиальная тема для архитектурных видеокарточек.

- Основной фон: `#35161D` — глубокий винный.
- Вторичный фон: `#4B2029` — бордовый.
- Светлая поверхность: `#F3EBDD` — тёплый айвори.
- Акцент: `#C6A15B` — матовая латунь.
- Основной текст: `#F8F1E6`.
- Тёмный текст: `#2A171B`.
- Приглушённый текст: `#BFAFA3`.
- Заголовки: элегантная антиква с широким трекингом.
- Служебный текст: нейтральный гротеск.

Композиция: асимметричные журнальные поля, тонкие латунные линии,
крупная архитектурная фотография, римские номера разделов и минимум декора.
